Gestion de redirections via Réglages → Redirections (301/302/307/308). Stockage en option. Redirections non actives dans l’admin.

== Installation ==
1. Uploadez `lika-redirect-manager` dans `wp-content/plugins/`.
2. Activez le plugin dans Extensions.
3. Réglages → Redirections.
